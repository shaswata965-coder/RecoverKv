% Decode efficiency, one table per decode length (256/8192, 256/16384):
% full KV (eager, flash), MiKV, ResQ, ours. Needs \usepackage{booktabs}.

% Transcribed from two perf-table printouts, both A100-80GB, one GPU, fp16:
%   ours     cache_budget 0.20, q 0.70 (bytes), gate 0.25, local 128, sink 5,
%            window 8
%   full KV  outputs/efficiency_fullkv_2f06bc4 (runs=1, warmup=0, stat=median)
% TTFT and TPOT are in seconds exactly as printed; TPOT is steady state.
% Decode is the printed decode tok/s, i.e. B / TPOT. Peak is the whole-run peak
% allocated, weights included. The printers say "GB" but divide MiB by 1024, so
% it is GiB, 14.96 of it weights.
% The full-KV printout has no TTFT column, so those cells are "--" until it is
% taken from that run. MiKV and ResQ are "--" until those baselines are run.
% OOM at 256/16384, B = 32 is inferred, not printed: both full-KV arms printed
% "-" there, and their measured peak grows 2.06 (flash) / 2.29 (eager) GiB per
% sequence from B = 8 to 16 at that shape, i.e. ~81 / ~88 GiB at B = 32.

% because only ours has one. Recheck bold once the "--" cells are filled in.
