% Full write-up, definitions and checks: reports/promotion_mass_q0.7_wikitext.md.
%
% Columns -- all on the same prompts and queries:
%   With gated promotion  the measured run (quant_promotion: bidir; the card gate
%                         reads 7 of 26 int2 windows per KV head at q = 0.70).
%   With promotion        the same run with the gate off: every int2 window read, as
%                         in the paper's pilot. Same tiers and scores (a replay), so
%                         the rows the gate cannot move carry the measured values;
%                         R_Q is "--": the 2-bit read of the windows the gate skipped
%                         is never recorded by a gated run. A --gate-ratio 1.0
%                         collector run fills it.
%   No promotion          the one-way policy (quant_promotion: oneway) REPLAYED on the
%                         run's own ranking signal, gated: the gate re-run by its own
%                         rule on the recorded cards, with the windows the run had
%                         promoted always read (favours no promotion). The replay
%                         reproduces the recorded tiers at 16,384 / 16,384
%                         layer-evictions (bidir). Not a recorded one-way run.
%   Delta                 with gated promotion minus no promotion, paired per
%                         (prompt, layer) trace.
%
% R_Q, "FullKV attention mass preserved": per query head and step, each int2
% window's FullKV attention against the attention the decode step gives it (its
% 2-bit read, or its card fill if the gate skipped it), rescaled to FullKV by the
% exactly-read local band; sum of min(credit, FullKV) over the int2 tier's FullKV
% attention. Scored on the head-steps both arms can credit (99.9% at q = 0.70,
% 95.4% at q = 0.20).
% Rows below the rule: a share of each query head's FullKV attention per decode step.
% "Contested fp slot": the next 32 steps' attention per step on the window a
% promotion puts in fp vs the fp window demoted for it (which keeps the slot without
% promotion).
% Bold: the with-gated-promotion value where its paired 95% bootstrap CI (256
% traces) excludes zero in its favour and the difference shows at the printed
% precision; the no-promotion value where the reverse holds (QSA at q = 0.20: in a
% replay both arms carry the same scores, so QSA moves only by which windows sit in
% int2). The gate-off column is never bold: its 0.00% card-fill row is by
% construction.
