% Q->F promotion, the paper's Table 18 layout, on the q = 0.70 collector run (and
% q = 0.20 for context). Needs \usepackage{booktabs}.
%
% Source: reports/promotion_ablation/q0.7.json and q0.2.json, written by
%   python -m modules.evaluation.promotion_ablation --zip <run>.zip --out-dir ...
% Full write-up, definitions and checks: reports/promotion_mass_q0.7_wikitext.md.
%
% "With promotion" is the measured run. "No promotion" is the one-way policy
% (quant_promotion: oneway) REPLAYED on that run's own ranking signal, same queries,
% same bytes; the read gate re-run by its own rule on the recorded card estimates,
% with the windows the run had promoted always read (the bracket that favours no
% promotion -- gate-dependent deltas are lower bounds). The replay reproduces the
% recorded tiers at 16,384 / 16,384 layer-evictions (bidir); it is not a recorded
% one-way run. A collector run with --promotion oneway replaces it.
%
% Rows below the rule are attention mass: a share of each query head's FullKV
% attention per decode step. "fp slot" row: the next 32 steps' mass per step of the
% window a promotion puts in fp (with) vs the fp window demoted for it, which keeps
% the slot under one-way (no promotion).
% Bold: the better value where the paired 95% bootstrap CI (256 prompt x layer
% traces) of the difference excludes zero and it shows at the printed precision.
% QSA at q = 0.20 is bold on the no-promotion side on purpose: in a replay both arms
% carry the same scores, so QSA moves only by which windows sit in int2.

\caption{Effect of Q$\to$F promotion at quant ratio 0.70 (2 fp + 26 int2 windows,

decode steps. Both columns use the same prompts and queries: \emph{with promotion}
is the measured run, \emph{no promotion} replays the one-way policy on that run's
ranking signal, a paired comparison. $R_Q$: share of the int2 tier's FullKV
attention in windows the read gate opens, per query head. Promotion does not change
which windows are kept (identical at every eviction, hence equal R3 FMM); it changes
which of them are read every step.}
